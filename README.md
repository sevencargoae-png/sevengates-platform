# منصة SEVENGATES

موقع عملاء + لوحة تحكم داخلية لشركة SEVENGATES للصيانة العامة والمقاولات.
مبني بـ Node.js (Express) وقاعدة بيانات Postgres — تم اختباره محليًا وكل شيء يعمل.

## المحتوى
- `public/index.html` — الموقع العام (الخدمات + فورم طلب الصيانة).
- `views/dashboard.html` — لوحة تحكم الفريق (محمية بكلمة مرور).
- `views/login.html` — صفحة دخول الفريق.
- `server.js` — السيرفر وكل الـ API.
- `db/schema.sql` — بنية قاعدة البيانات (تتطبق تلقائيًا أول ما السيرفر يشتغل).

## خطوات النشر (بدون كتابة أي كود)

### 1) رفع الكود على GitHub
1. ادخل على github.com وسجّل دخول.
2. اعمل New repository باسم `sevengates-platform` (خليه Public).
3. من صفحة الريبو الفاضية، دوس "uploading an existing file".
4. اسحب كل الملفات والمجلدات اللي جوه الفولدر ده (بما فيها `.gitignore` و`.env.example`) وارفعها، ودوس Commit changes.

### 2) قاعدة البيانات على Render
حساب Render بتاعك متصل بالفعل. هنعمل قاعدة بيانات Postgres جديدة ونربطها بالخدمة — الخطوة دي هعملها أنا مباشرة بعد ما تأكدلي إن الريبو اتظبط.

### 3) خدمة الويب على Render
هنربط الريبو اللي رفعته بخدمة ويب جديدة على Render، ونضبط متغيرات البيئة دي (Environment Variables):
- `DATABASE_URL` — هتتظبط تلقائيًا لما نربط قاعدة البيانات.
- `ADMIN_PASSWORD` — كلمة مرور دخول لوحة التحكم لفريقك (اختار كلمة قوية).
- `JWT_SECRET` — أي نص عشوائي طويل (هقترحلك واحد).

### 4) الدومين الخاص بيك
بعد ما الموقع يشتغل على رابط `xxx.onrender.com`، تقدر تربط دومين خاص بيك (زي sevengates.com) من إعدادات الخدمة في Render → Custom Domain، وتوجّه الدومين من عند البائع اللي اشتريت منه (GoDaddy, Namecheap, إلخ) حسب التعليمات اللي هتظهر هناك.

## ملاحظات مهمة
- **الفريق يدخل من:** `/staff` (هيوديك لصفحة الدخول تلقائيًا لو مش مسجل دخول).
- **العميل يدخل من:** الرابط الرئيسي للموقع مباشرة.
- **الصور:** بتتخزن جوه قاعدة البيانات نفسها (بعد ضغطها تلقائيًا في المتصفح) — مفيش حاجة إضافية مطلوبة.
- **الخطة المجانية على Render:** الخدمة بتنام بعد فترة عدم استخدام وبتاخد كام ثانية تصحى أول ما حد يفتح الرابط، وقاعدة البيانات المجانية عندها حد أقصى للتخزين ومدة صلاحية — راجع تفاصيل خطط Render لو حبيت تترقّى لخطة مدفوعة بسيطة لثبات أعلى.
